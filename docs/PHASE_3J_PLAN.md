# Phase 3J: Global Quick Add

## Status

Complete.

## Goal

Reduce mobile navigation effort by putting every existing household creation workflow in one predictable place.

## Delivered

- A static, mobile-first `/add` hub.
- A global header shortcut with an accessible label and tooltip.
- Direct links for rooms, categories, assets, maintenance tasks, reminders, providers, warranties, receipts and documents.
- Clear grouping across inventory, maintenance and records.
- Database-free route smoke coverage.
- Updated application map and acceptance documentation.

## Behaviour

Quick Add only links to existing guarded forms. It does not add a mutation, bypass validation, pre-create a record or change database access behaviour.

## Scope

No schema, action, dependency, analytics, account, notification, upload, storage, AI, OCR, payment or native project is added.
