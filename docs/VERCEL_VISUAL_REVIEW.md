# Vercel Visual Review

Vercel Preview Deployments are the visual review gate for pull requests.

## Setup

The client must connect the GitHub repository to Vercel and choose the Next.js preset. Phase 1A does not require production environment variables.

## Review Steps

- Open the preview URL from the PR.
- Review mobile width first.
- Check each placeholder route.
- Confirm the visual shell matches the approved Phase 1A scope.
- Record feedback on the PR.
