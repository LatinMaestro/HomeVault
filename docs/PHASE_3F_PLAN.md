# Phase 3F: Maintenance Starter Templates

## Status

Complete.

## Goal

Help beginner households create useful recurring maintenance tasks without requiring them to invent every title, description and interval.

## Delivered

- A mobile-first maintenance template library.
- Eight curated Australian household starting points across comfort, safety, exterior, water and garden care.
- Editable task-form prefilling through URL selection.
- Clear safety and local-guidance boundaries.
- Direct access from the maintenance screen.
- Unit and database-free route coverage.

## Behaviour

Selecting a template opens the existing guarded maintenance form with title, description, frequency and active status prefilled. Asset, provider, due date and every other field remain under household control. Saving continues through the existing preview database gate.

Templates are static starting points. They do not create tasks automatically, send reminders, claim to replace manuals or professional advice, or change existing task records.

## Scope

No schema, dependency, external service, notification delivery, automatic task creation, location tracking, financial feature, AI, OCR, storage or native project is added.
