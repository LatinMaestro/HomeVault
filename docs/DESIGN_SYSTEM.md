# Design System

## Direction

HomeVault should feel calm, practical and trustworthy. The interface should suit repeated household admin tasks, especially on mobile.

## Palette

- Primary: deep teal/green.
- Secondary: soft mint.
- Background: warm neutral.
- Text: high-contrast green-neutral.
- Borders: quiet neutral green.

## Components

- Use shadcn-compatible primitives.
- Cards are for individual repeated items and summaries.
- Navigation should be obvious and thumb-friendly.
- Avoid marketing-style layouts inside the app.

## Accessibility

- Use semantic landmarks.
- Keep contrast readable.
- Preserve keyboard navigation.
- Use descriptive labels and page titles.

## Installed Mobile Experience

- Respect iOS and Android display cutouts using safe-area insets.
- Keep primary controls at least 44 CSS pixels high where practical.
- Avoid hover-only interactions.
- Preserve readable content with browser and OS text scaling.
- Treat standalone display mode as a first-class viewport.
- Final native shells must use platform-appropriate back behavior, launch treatment and accessibility semantics.
