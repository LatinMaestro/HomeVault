# UI Review Guide

Review the Vercel Preview URL on a mobile viewport first, then desktop. The client should not need to run the app locally for normal review.

## Primary Surfaces

- Home dashboard and review-status panel.
- Vault overview.
- Rooms list, create shell and edit shell.
- Assets list, detail, create shell and edit shell.
- Maintenance list and detail.
- Warranties list and detail.
- Receipts/Documents metadata list and detail.
- Settings placeholder.

## Check

- Brand is clear as HomeVault.
- Navigation includes Home, Vault, Maintenance, Warranties, Receipts and Settings.
- Active navigation state is visually clear.
- Mobile layout is usable before desktop polish.
- Text is readable and not cramped.
- Cards describe practical household workflows.
- Empty states are useful when no records are available.
- Missing detail pages explain the data source and provide a path back.
- Create/edit shells clearly say saving is not enabled yet.
- The experience feels calm, practical and beginner-friendly.
- No unapproved features are implied as working.

## Out-Of-Scope Signals To Reject

- Production authentication.
- Uploads or production file storage.
- OCR or AI.
- Notifications.
- Payments or subscriptions.
- Analytics.
- Native iOS.
- Delete actions or persistent create/edit mutations.
- Financial or budgeting features.
