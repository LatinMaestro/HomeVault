# Build Plan

## Phase 1A: Foundation

Create the docs, app shell, placeholder routes, visual identity and Vercel review workflow.

## Phase 1B: Data Model

Confirm PostgreSQL provisioning, then implement Prisma schema, migrations and seed data.

## Phase 1C: Core Screens

Build core browse/create/edit flows for rooms, assets, maintenance tasks, warranties and receipt metadata.

## Phase 1D: Review And Hardening

Improve accessibility, error states, responsive behavior, test coverage and deployment readiness.

## Future Phases

Add approved production auth, approved storage, reminders, sharing and native app exploration only after client decisions.
