# Phase 11B: Release Regression Manifest

Status: prepared executable-evidence contract; no release candidate or physical-device run is claimed as passed.

## Purpose

This manifest converts the approved core-plus-optional product scope into one exact-candidate regression boundary. A checklist, source inspection, skipped job or successful predecessor cannot create acceptance evidence.

## Hosted Regression Evidence

- Every hosted case binds a versioned evidence identity to the exact candidate ID/revision and release commit.
- Evidence records the real workflow, job, durable artifact digest, covered platforms and execution window.
- Jobs must execute and pass. Missing steps, zero-job startup failures, stale evidence and caller-supplied truthy values fail closed.
- Every executable case uses fictional data and proves its negative authorization/privacy control.
- Stateful cases prove cleanup of their synthetic records, files, tokens, grants, queues, device state or processor state.
- Cross-platform cases must cover every assigned web, iOS and Android surface on the same candidate.

## Required Scope

- Identity, recovery, sessions, roles, invitations, ownership and property isolation.
- Core records, private files, recurrence, search, archive and error states.
- Notifications, calendar sync, biometrics, capture, offline data and native utilities.
- Expanded attachments, OCR/AI drafts, email quarantine, controlled sharing and provider handoffs.
- Privacy-safe diagnostics and approved commercial lifecycle behaviour.
- Accurate no-store exports and complete account/property deletion.
- Accessibility, layout, performance, resilience and the synthetic reviewer journey.

## Physical-device Boundary

- Hosted evidence can reach only `ready-for-physical-device-gates`.
- iOS and Android completion requires the exact signed artifact digest, device/OS, tester authority, fictional fixtures, negative controls and cleanup evidence.
- Hosted or simulated results cannot impersonate physical-device evidence.
- Physical-device evidence remains a client-owned gate and expires after seven days.

## Release Boundary

This contract does not merge branches, sign artifacts, create store records, complete client gates, upload to TestFlight or submit to App Review. It prepares the evidence shape those later steps must satisfy.
