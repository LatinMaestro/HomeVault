# Acceptance Criteria

## Phase 1A

- Documentation suite exists.
- Next.js app runs locally.
- Home, Vault, Maintenance, Warranties, Receipts and Settings routes exist.
- Home dashboard shows placeholder cards for maintenance, warranties, assets, receipts/documents and inventory summary.
- Styling is mobile-first, calm and home-focused.
- `npm run build` passes.
- README explains local setup and Vercel review.
