# HomeVault Plan

## Phase 1A: Foundation

- Create complete documentation suite.
- Scaffold deployable Next.js shell.
- Add placeholder navigation and pages.
- Establish visual direction and review workflow.

## Phase 1B: Data Model

- Finalise Prisma schema after database approach approval.
- Add seed data and local-only development fixtures.
- Keep storage references as metadata only until file storage is approved.

## Phase 1C: Core Screens

- Build practical CRUD flows for rooms, assets, warranties, receipts and maintenance records.
- Keep auth single-user and stubbed unless a production auth decision is approved.

## Later Phases

- Production authentication.
- Approved file storage.
- Reminder delivery.
- Multi-home or family sharing if validated.
- Native app only if the web app proves the need.
